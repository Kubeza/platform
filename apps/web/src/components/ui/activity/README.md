# Activity

Enterprise-ready activity feed components for dashboards, audit logs, deployment history, and system timelines.

## Components

- ActivityProvider
- ActivityFeed
- ActivityList
- ActivityItem
- ActivityAvatar
- ActivityIcon
- ActivityTitle
- ActivityDescription
- ActivityTimestamp
- ActivityBadge
- ActivityActions
- ActivityGroup
- ActivityEmpty
- ActivitySkeleton

## Hook

```tsx
const { activities } = useActivity();
```

## Utilities

- formatActivityTimestamp()
- groupActivities()
- sortActivities()
- filterActivities()

## Features

- React 19
- TypeScript
- Tailwind CSS v4
- shadcn/ui compatible
- Accessible
- Dark mode compatible
- Enterprise dashboard ready
