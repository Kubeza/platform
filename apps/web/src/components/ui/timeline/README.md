# Timeline

Enterprise-ready timeline components for visualizing deployments, releases, incidents, audit logs, CI/CD pipelines, and chronological events.

## Components

- TimelineProvider
- Timeline
- TimelineList
- TimelineItem
- TimelineMarker
- TimelineConnector
- TimelineContent
- TimelineTitle
- TimelineDescription
- TimelineTimestamp
- TimelineBadge
- TimelineActions
- TimelineGroup
- TimelineEmpty
- TimelineSkeleton

## Hook

```tsx
const { items } = useTimeline();
```

## Utilities

- formatTimelineTimestamp()
- sortTimelineItems()
- groupTimelineItems()
- filterTimelineItems()

## Features

- Vertical timeline
- Event grouping
- Severity badges
- Timeline markers
- Event connectors
- Action buttons
- Loading skeleton
- Empty state
- React 19
- TypeScript
- Tailwind CSS v4
- shadcn/ui compatible
- Dark mode support
- Enterprise dashboard ready
